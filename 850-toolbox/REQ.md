# 850 Toolbox — 需求文档

## 概述

850 Toolbox 是一个 OMS 数据看板系统，支持桌面和移动端实时查看 K1 PRD 订单数据、出货数据、优先级排序。通过 PWA + 公网隧道实现手机上像原生 App 一样使用。

## 用户角色

| 角色 | 场景 | 设备 |
|------|------|------|
| 运营/物控 | 办公室日常查看 K1 数据 | 桌面电脑 |
| 管理者 | 外出/会议中快速查看出货状态 | 手机 |
| 其他同事 | 通过分享链接查看看板 | 任意设备 |

## 功能需求

### F1 · K1 PRD 看板 V3.3
- 订单总览：订单总数 / Backlog / 已出货
- 分类明细：CTO P1 / FGA / RTL / CTO P2 各出货状态
- 区域分布：DAO / APJ / EMEA × 订单类型 交叉表 + 堆叠柱状图
- 生产状态：STBL / ATB / WIP / FG / SN 双分类
- 出货计划：MSBD 未来 7 天 / CTO P1 28H
- 下钻明细：点击任意数字弹出 500 条订单明细 + CSV 下载
- 日期筛选：PO 接收日期 / MSBD 日期

### F2 · 当日看板
- 新收订单 / 今日出货 / ASN / SN S 四指标
- NACK / ZC 异常统计
- 类型 × 区域 × 货代 圆环图
- 出货进度（ASN / PPS / 车辆）
- 30 天出货趋势折线图

### F3 · 公网访问
- 任意网络、任意设备通过 HTTPS 地址访问
- 无需 VPN、无需安装

### F4 · 手机 PWA
- 添加到主屏幕 → 全屏 App 体验
- 底部 4 图标导航（首页 / K1 / 出货 / 排序）
- 触控友好的按钮和图表尺寸
- 离线时显示上一次缓存数据

### F5 · 自动数据拉取
- 后台每 10 分钟自动从 OMS 拉取最新数据
- 浏览器每 5 分钟自动刷新
- 启动时立刻拉取一次

### F6 · 工具箱其他工具
- 优先级排序（拖拽 + 筛选 + 导出）
- 出货历史（按天/周/月/季/年统计）
- 870 FGA 优先级分配
- A2 FGA/RTL 报告

## 非功能需求

| 需求 | 指标 |
|------|------|
| 数据新鲜度 | ≤10 分钟（auto_pull 间隔） |
| 页面响应 | 首次加载 <5 秒 |
| 公网可用性 | 7×24（PC 开机时） |
| 离线降级 | 断网时显示缓存数据 + 时间戳 |
| 安全性 | HTTPS + 仅读取内网 OMS 数据 |

## 数据流

```
OMS 服务器 (内网)  →  server.py (本地 :8500)  →  浏览器/手机
     ↑ 每10分钟                ↑ 每5分钟              ↑
  auto_pull 线程           app.js 自动刷新        PWA 安装
```
